# Core Flow Graph

```text
首次启动/项目列表
  --[添加本地项目]--> 系统目录选择器 --[选择]--> 项目概览
项目概览(未保护) --[开启版本保护]--> 初始保存点成功 --> 时间线
时间线 --[创建保存点]--> 名称确认 --[保存]--> 新时间线节点
时间线节点 --[查看这次改了什么]--> 保存点详情 + 文件 Diff
保存点详情 --[回到这个版本]--> 创建保险点 + 影响预览
影响预览 --[再次确认]--> 回退结果 --[撤销本次回退]--> 恢复回退前版本
项目概览 --[GitHub 备份]--> 登录/远程/扫描状态
备份设置 --[扫描通过并备份]--> 已同步
备份设置 --[发现风险]--> 风险列表 --[加入 .gitignore]--> 重新扫描
侧栏 --[设置]--> Git/数据目录/Agent 连接状态
```

关键状态：空、加载、成功、可重试错误、无变化、GitHub 未登录、Agent 未连接、危险操作二次确认。
