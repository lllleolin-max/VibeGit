# Interface Directions

## A. 引导式时间线工作台（采用）

- 结构：项目侧栏 + 保存点时间线 + 按需出现的详情抽屉。
- 主操作：顶栏固定“创建保存点”，时间线节点内提供“查看改动”“回到这里”。
- 优化：低认知负担、版本安全感、核心闭环连续性。
- 代价：批量 Git 操作效率不如专业客户端。

## B. 安全控制中心

- 结构：健康分数/风险卡片在首页，版本历史作为二级页面。
- 优化：首次用户快速理解是否安全。
- 代价：频繁查看历史时跳转较多，弱化“每轮 AI 修改”的连续故事。

## C. Agent 会话优先

- 结构：以 Codex/Claude 任务为主列表，每个任务内折叠保存点与 diff。
- 优化：清楚回答“哪个 Agent 改了什么”。
- 代价：手动修改与跨 Agent 版本不容易形成统一历史。

选择 A。它最直接服务“保存—理解—恢复”闭环；Agent 与 GitHub 状态作为时间线元数据呈现。
